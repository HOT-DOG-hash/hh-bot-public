# MIGRATION_RISKS — платежный контур

| Риск | Описание | Вероятность | Влияние | Митигирующие меры |
|------|----------|-------------|---------|-------------------|
| Блокировки при ALTER TABLE payments | Добавление колонок и индексов на большой таблице может удерживать lock | Средняя | Высокое (downtime) | Работать в off-peak, операции add column (быстрые), индексы строить CONCURRENTLY, прогонять на staging |
| ENUM расширения | Неправильное создание/удаление ENUM может блокировать связанные объекты | Средняя | Среднее | Idempotent DO-block, в downgrade drop type if exists, dry-run |
| Бэкфилл данных | Неверные значения idempotency_key/plan_code могут сломать идемпотентность | Средняя | Высокое | Backfill на копии, валидировать count и уникальность, ручная проверка выборки |
| Ретраи и dual-write | В период dual-write возможны разные источники правды | Низкая | Среднее | Фичефлаг, логирование сравнения, четкий план включения/отключения |
| Отсутствие исторических вебхуков | Невозможно восстановить payment_events | Высокая | Низкое (аналитика) | Создать placeholder события, задокументировать отсутствие истории |
| Производительность индексов | Создание комбинированных индексов на больших таблицах | Средняя | Среднее | CREATE INDEX CONCURRENTLY, мониторинг VACUUM/ANALYZE |
| Откат после contract | Трудно восстановить старые ограничения (provider, external_id) | Низкая | Среднее | Сохранить SQL для revert, иметь pg_dump перед contract |
